## Design

- Read DESIGN.md before touching any UI. If it still has placeholders, run `design-taste` and fill it in with the user first.
- Colours, fonts, spacing and radius come from the tokens. A raw hex value or a one-off size in a component is a defect.
- Real content only. No lorem ipsum, no invented numbers, testimonials or logos.
- Every interactive element has all its states (`ui-states`).
- UI work is judged on screenshots at 1440, 768 and 390 pixels wide, not on the code. Take them, look at them, or send them to the `design-critic` agent.
